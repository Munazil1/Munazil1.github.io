# munazil1.github.io

Personal portfolio of Munazil V, Machine Learning Engineer.

Live site: https://munazil1.github.io

## Updating

- **CV:** replace `resume.pdf` with your latest CV (keep the filename).
- **Screenshots or demo videos:** add files to `assets/`, then uncomment the example `<img>` tag inside a case study in `index.html`. Use dummy data only: never real ID documents, faces, receipts, or client names.
- **New project:** copy one `<article class="case">` block in `index.html` and edit it.
- **Date:** update "Last updated" in the footer when you change content.
