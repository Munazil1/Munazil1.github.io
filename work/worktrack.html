WorkTrack

AI event staffing platform

Assigns the right staff to each event automatically, replacing a spreadsheet process that took about three hours per event.

3 h to 10 stime per staffing decision
60+REST endpoints
10 min to 10 sworkflow latency after redesign

The problem

Staff were assigned to events by hand from spreadsheets. Each event took about three hours to staff, and double-bookings slipped through.

How it works

  1. Start with the full pool

    Every staff member is a candidate when a new event is created.

  2. Apply the rules

    Plain code removes anyone unavailable, double-booked, on leave, or over their workload.

  3. Rank the shortlist

    An OpenAI model ranks the remaining candidates against the event's skill needs and returns validated, structured results.

  4. Save a snapshot

    Each recommendation is stored as an immutable record of what the model saw and chose.

  5. Admin approves

    An admin reviews and accepts assignments in a batch, and staff are notified.

Amber steps are where a person makes the call.

What I built

I built the complete backend: authentication, role-based access, staff, event, and assignment modules, notifications, and a super-admin area for managing multiple organizations and onboarding admins. I also drove the frontend integration through to production.

It runs on Azure with automatic deployment from GitHub, daily database backups kept for seven days, firewall hardening, and fixes that keep each organization's data isolated.

Key decisions

  • Rules before the model

    Anything a rule can decide never reaches the LLM. That cut cost and latency, and made each result easy to explain.

  • Every decision is a snapshot

    Immutable records make it possible to answer why a person was picked, long after the fact.

  • Fast feedback for admins

    I redesigned a slow polling workflow so updates arrive in about 10 seconds instead of 10 minutes.

The code belongs to Pure Magic IT and its client, so it isn't public. I'm happy to walk through it in an interview.
